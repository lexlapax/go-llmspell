## Data Flow Example: LLM Chat

```
┌─────────────────────────────────────────────────────────────────────────┐
│ Lua Script: result = llm.chat({model="gpt-4", messages={...}})         │
└────────────────────────┬────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ llm.lua: Validates params, calls bridges.llm_core:chat(params)         │
└────────────────────────┬────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ LLMAdapter: Converts Lua table → Go ChatRequest                        │
└────────────────────────┬────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ LLMBridge: Calls go-llms Chat() method                                 │
└────────────────────────┬────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ go-llms: Executes chat with provider (OpenAI, Anthropic, etc.)         │
└────────────────────────┬────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ Response flows back: go-llms → Bridge → Adapter → Lua                  │
└─────────────────────────────────────────────────────────────────────────┘
```

## Bridge Registration Flow

```
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│ Bridge Registry  │────▶│ Feature Sets     │────▶│ Bridge Factory   │
└──────────────────┘     └──────────────────┘     └────────┬─────────┘
                                                            │
                         ┌──────────────────────────────────┘
                         ▼
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│ Create Bridges   │────▶│ Register with    │────▶│ Create Adapters  │
│ (agent, llm...)  │     │ BridgeManager    │     │ if needed        │
└──────────────────┘     └──────────────────┘     └────────┬─────────┘
                                                            │
                         ┌──────────────────────────────────┘
                         ▼
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│ Expose in Lua    │────▶│ Global 'bridges' │────▶│ Available to     │
│ via bridges.*    │     │ table populated  │     │ stdlib modules   │
└──────────────────┘     └──────────────────┘     └──────────────────┘
```

## Security Model

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          Security Profiles                               │
├─────────────────┬────────────────────┬──────────────────────────────────┤
│    Untrusted    │     Trusted       │          Privileged              │
├─────────────────┼────────────────────┼──────────────────────────────────┤
│ • Core bridges  │ • Core bridges    │ • All bridges                    │
│ • No file I/O   │ • LLM bridges      │ • Full file system              │
│ • No network    │ • State bridges    │ • Network access                │
│ • Limited CPU   │ • Limited file I/O │ • No resource limits            │
└─────────────────┴────────────────────┴──────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                     Feature Set Mapping                                  │
├─────────────────┬────────────────────┬──────────────────────────────────┤
│ BridgeSetCore   │ BridgeSetLLM      │ BridgeSetAll                    │
│ BridgeSetUtil   │ BridgeSetState    │                                  │
│                 │ BridgeSetAgent    │                                  │
└─────────────────┴────────────────────┴──────────────────────────────────┘
```
